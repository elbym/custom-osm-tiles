# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Pre-renders static Leaflet raster tiles for a small area around one marker, per website project, so the site needs no third-party map requests (privacy). User-facing docs are in German (README.md); answer the user in German.

## Commands

```sh
# full run (podman required, not docker); test area = Herford
./make-tiles.py --lat 52.115 --lon 8.67 --radius 5 --out out/test
# preview: open out/<name>/index.html directly via file://
```

There are no tests. To check a rendering change, re-run into `out/test` (`rm -rf out/test` first) and look at a PNG near the marker, e.g. `out/test/tiles/16/34345/21613.png` and `out/test/tiles/18/137385/86453.png` for the Herford test point.

## How it fits together

- `make-tiles.py` (stdlib only) does everything:
  1. Planetiler container builds `data/<area>.mbtiles` from a Geofabrik extract (default `detmold-regbez`). The result is cached; delete it to refresh the OSM data.
  2. Starts tileserver-gl on **127.0.0.1:8089**, because 8080 is taken by ddev on this machine. `style/` is mounted as `/data`, and the mbtiles as `/data/tiles.mbtiles`.
  3. Fetches only the needed `{z}/{x}/{y}.png`, stops the container, copies `vendor/leaflet/` and fills `template.html` (replacing the `/*CONFIG*/{}` placeholder with JSON) into `out/<name>/index.html`.
- **The script and `template.html` are coupled.** The tile coverage in `tiles_for()` assumes Leaflet's `maxBounds` = the `--radius` bbox:
  - At low zooms the viewport is bigger than the bbox, so the script renders one `--viewport` worth of tiles around it.
  - From `--detail-from` (17) on, tiles are rendered only within `--detail-radius`. The template's base layer uses `maxNativeZoom` = detail_from−1 to upscale outside that area.
  - Change both sides together.
- Vector data only goes to z14; tileserver-gl overzooms for z15–18.

## Style (`style/`)

- `style.json` is OpenFreeMap's OSM Bright with these changes:
  - the source is `mbtiles://{osm}` (see `config.json`), and the `ne2_shaded` raster layer is removed;
  - glyphs and the sprite (`ofm*`) are local;
  - labels use DINish with Noto Sans as fallback;
  - all `text-size` values are scaled ×1.15, except the `*shield*` layers.
- When editing `style.json` programmatically, don't re-apply that scaling.
- Fonts are glyph PBFs in `style/fonts/<Font Name>/`, generated by `build_pbf_glyphs fonts-src style/fonts`. The tool only reads TTF/OTF and names output folders after the file stem, so rename each folder to match the name used in `text-font`.
- `fonts-src/` holds the source TTFs plus their license. Noto Sans fallback glyphs are gitignored (100 MB); `ensure_noto()` downloads them on first run.
